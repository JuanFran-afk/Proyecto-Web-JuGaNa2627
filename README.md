# 🚀 Proyecto-Web-JuGaNa2627: Control de Versiones con Git y GitHub

¡Bienvenido/a al repositorio de mi primer proyecto web interactivo! Este proyecto forma parte de la asignatura de programación y está diseñado para aplicar y dominar los conceptos clave del control de versiones distribuido.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica del sitio web.
* **CSS3:** Estilos y diseño visual.
* **Git:** Control de versiones local para el seguimiento del historial de commits.
* **GitHub:** Hosting del repositorio remoto y gestión de la rama principal (`main`).

---

## 📌 Flujo de Trabajo Realizado

En este proyecto se han practicado las siguientes operativas de Git:

1. **Inicialización y configuración:** Creación del repositorio local y rama principal `main`.
2. **Gestión de commits:** Registro incremental de cambios mediante `git add` y `git commit`.
3. **Control de estados:** Descarte y restauración de cambios en el área de trabajo con `git restore`.
4. **Sincronización remota:** Vinculación con el repositorio de GitHub (`origin`) mediante `git remote add` y publicación de ramas con `git push -u`.
